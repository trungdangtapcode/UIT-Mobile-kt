# Android platform figure

`choose-domains.png` is a 1016 × 2070 RGBA raster rendering of the official
[choose-domains.svg](https://developer.android.com/static/images/training/app-links/choose-domains.svg).
Android Developers publishes it in
[Verify App Links](https://developer.android.com/training/app-links/verify-applinks#make-the-request)
under the [Android Developers Content License](https://developer.android.com/license).
CairoSVG rendered the original artwork without clipping. The visible app
“YourApp” is a documentation example, separate from the live experiment.
